here is the plan:

Sanjeevani — AI Emergency Medical Logistics UI

A dark-first (with light mode), glass-and-glow web app that feels like a live AI emergency control room, softened with ayurvedic/nature calm. Frontend only, mock data, with a clearly marked API layer ready for your backend.

Palette & identity

Tokens from your palette, defined as semantic design tokens (oklch) in src/styles.css:

#484458 slate-violet surfaces

#49427d deep violet gradients

Light mode inverts to a soft parchment/rose base with the same violet accents. Dark/light toggle in the navbar, persisted.

Word logo: "Sanjeevani" set in a refined display face with a subtle animated glow sweep — no icon mark, no cartoon elements.

Pages

Home (/) — the calm one

Full-bleed nature/ayurveda background image (your upload) with a slow parallax drift and a violet gradient veil for legibility.

Centered app name at the top, subheading, brief description.

Text sections fade in and fade out on scroll (opacity + slight blur only — no upward slide), one idea on screen at a time.

About section, then a quiet CTA into the dashboard.

Cursor: soft violet particle trail + glow distortion on hover, active across the site.

Dashboard (/dashboard) — the control room

Solid/gradient background (no photo), three-zone layout.

Left glass panel: Request Equipment — hospital select, equipment type, nearby lenders list with ETA / availability / cost, glowing "Request Now" CTA with ripple.

Center: stylized satellite-look map (canvas/SVG, no API key) with pulsing hospital nodes, glowing 15-min isochrone rings, and an animated flowing route line drawn when a request fires.

Right glass panel: live status (IN_TRANSIT / DELIVERED / ESCROW LOCKED), animated timeline log, QR + transaction-hash block with a blockchain feel.

Marketplace (/marketplace) — browsable equipment listings from lenders: filters (equipment, distance, price), glass cards with availability state, hover glow, request action that hands off to the dashboard flow.

Analytics (/analytics) — same ambient background, with an inset "screen within a screen": a bezelled glass console that contains all charts — response-time trend, fulfilment rate, equipment demand mix, hospital leaderboard — with animated draw-in.

AI Assistant (/assistant) — a full ChatGPT-style page: conversation column, scripted-but-smart assistant replies, suggestion chips ("Find oxygen within 15 minutes", "Request from nearest hospital"), voice icon, streaming-style typing animation, and a floating fairy-doctor orb (idle float + glow pulse, brighter on hover) present site-wide that opens a slide-in chat panel or routes here.

Motion

Liquid-glass navbar: blurred, light-refracting, tabs Dashboard · Marketplace · Analytics · AI Assistant, plus theme toggle.

Route transitions: an "AI initializing…" loader with a soft particle bloom between pages; fade + scale + blur, 0.6–1s cubic-bezier easing.

Micro-interactions: button glow on hover, ripple on click, panel slide+fade+scale, pulsing map nodes, flowing route lines.

Optional ambient sound toggle in the navbar.

Backend integration note

All data comes from a single mock layer at src/lib/api/ — one function per endpoint you listed (POST /chat, POST /dispatch, POST /dispatch/preview, GET /hospitals, GET /hospitals/{id}, POST /hospitals, POST /inventory/upload, GET /inventory/{hospital_id}, GET /inventory/search, POST /gis/best-option, POST /gis/route, POST /gis/route-map, POST /gis/isochrone, POST /gis/isochrone-map, POST /events/loan-created, POST /events/delivery-confirmed, POST /events/loan-settled).

Each function returns mock data today and carries a header comment showing the exact fetch call to swap in, plus the expected request/response shape the UI consumes. A README in that folder explains the one-line switch (VITE_API_BASE_URL + flipping USE_MOCKS) to point everything at your server. UI components never call fetch directly, so merging is a single-folder change.

Technical notes

TanStack Start (React 19 + Vite) with file-based routes — this is the fixed router for the project; React Router is not used.

Motion (Framer Motion) for all animation; cursor trail and background particles on canvas for performance, with prefers-reduced-motion respected.

Map is hand-built canvas/SVG rather than Mapbox, so no token is needed and it matches the palette exactly; your /gis/route-map and /gis/isochrone-map responses can drive it later.

Tailwind v4 tokens only, no hardcoded colors; responsive desktop-first, tablet and mobile layouts collapse the three-panel dashboard into stacked glass cards.
