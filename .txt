## Guides to terminal
uvicorn GIS_engine.main:app --port 8001 --reload   -> for GIS_engine
uvicorn mcp_server.wrapper:app --port 9001         -> for mcp_server
uvicorn app.main:app --reload                      -> for backend

npx hardhat compile                                     -> for inital smart_contract compilation and artifacts , cache creation (one-time)
npx hardhat run scripts/deploy.ts --network localhost   -> for deployement to local ganache server at RPC:7545 
npx hardhat node                                        -> for active blockchain server
